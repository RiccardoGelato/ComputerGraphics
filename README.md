# ComputerGraphics
This project was developed during the course of Computer Graphics held by Politecnico di Milano. 
The objective, for our project, was to create a car videogame that could show different aspect of the course, such as:
- creating multiple shaders
- implementing different types of cameras
- handling the pipeline of multiple objects
- handling the transformations of objects
